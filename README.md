# AutoAim 自动瞄准点击器

一个 Android 自动瞄准点击器：截取要识别的目标图片作为模板，逐帧模板匹配（NCC）识别目标位置，自动滑动屏幕把目标移到屏幕中心，可任选一处点击；支持循环运行与开始 / 暂停 / 结束控制。

## 功能
- **截取模板**：悬浮窗「模板」→ 在截图上框选要识别的目标区域保存为模板。
- **自动归中**：每帧模板匹配 → 计算偏移 → 无障碍服务模拟滑动把目标拉到屏幕中心。
- **选择点击点**：可选自定义坐标或在瞄准后点击屏幕中心。
- **循环 / 控制**：可循环运行；悬浮窗提供暂停 / 继续 / 结束。

## 所需权限
- 屏幕录制（MediaProjection）：用于实时截屏识别。
- 无障碍服务（AccessibilityService）：用于模拟滑动与点击。
- 悬浮窗（SYSTEM_ALERT_WINDOW）：用于常驻控制面板。
- Android 13+ 前台服务通知权限。

## 使用流程
1. 打开 App →「开启无障碍服务」→「开启悬浮窗权限」。
2. 点「启动」→ 同意屏幕录制授权。
3. 悬浮窗点「模板」→ 在截图上拖动框选目标 →「确认截取」。
4. （可选）「选点」选自定义坐标，否则默认瞄准后点屏幕中心。
5. 引擎开始循环：识别 → 滑动归中 → 点击。悬浮窗可随时暂停 / 结束。

## 云编译（GitHub Actions，无需本地环境）
1. 把本仓库推到 GitHub（含 `.github/workflows/build.yml`）。
2. 进入仓库 `Actions` 标签，等 `Build APK` 工作流跑完（首次约 5~8 分钟）。
3. 进入绿色成功的工作流，从底部 `Artifacts` 下载 `AutoAim-debug` 的 ZIP，解压得到 `app-debug.apk`。
4. 把 APK 传到手机，允许「未知来源」安装即可。

## 本地编译（可选）
需 JDK 17 + Android SDK（compileSdk 34）+ Gradle 8.5（Wrapper 自动下载）：
```
./gradlew assembleDebug
```
产物在 `app/build/outputs/apk/debug/app-debug.apk`。

## 说明
- 识别基于 **OpenCV ORB 特征点匹配 + 单应矩阵**，对目标的**缩放与旋转具有不变性**，适合实战中目标大小 / 角度变化大的场景。
- 若目标纹理过少（纯色、模糊）导致特征点不足，识别会失效；此时请选择纹理更丰富的目标区域作为模板。
- 依赖「无障碍服务」与「屏幕录制」权限，请仅在你自己的设备上用于合规用途。
